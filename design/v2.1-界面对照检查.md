# v2.1 界面对照检查

对照来源：`咻咿待办-清单空状态回收站.png`、`咻咿待办-表单搜索弹窗.png`、`咻咿待办-交互状态.png`、`咻咿待办-组件风格板.png`，以及用户提供的手机截图。用户此前要求轻提示显示在顶部，此项优先于概念图中的底部提示位置。

| 界面或状态 | v2.1 检查与调整 |
| --- | --- |
| 首页清单 | 核对顶部云朵、标题、计数、三段筛选、任务卡片和底部按钮；增加标题下的浅紫装饰底线。 |
| 清单空状态 | 保留手账云朵插画；在可用列表区域居中，补齐参考文案。 |
| 新建、编辑 | 使用独立圆角分区、对应线性图标、分类和优先级图标标签；标题输入有铅笔图标、必填星号与清除按钮。 |
| 搜索及无结果 | 改为独立搜索界面，使用带放大镜及清除按钮的输入框；v2.2 加入分类、完成状态、优先级、截止时间组合筛选；无结果时显示云朵和清空搜索。 |
| 已完成 | 通过首页“已完成”分段进入；任务卡片使用浅绿色完成态。 |
| 回收站 | 仅显示任务标题、删除时间和描边恢复按钮；空状态使用云朵。 |
| 删除确认 | 改为居中的圆角卡片，加入珊瑚色垃圾桶、居中文字、关闭按钮、描边取消和实底删除按钮。 |
| 日期和时间 | 改为应用内双列滚轮弹窗，支持选择具体分钟。 |
| 提醒权限 | 改为云朵插画与上下排列按钮的应用内说明弹窗；Android 权限确认仍由系统展示。 |
| 轻提示 | 按用户要求显示在状态栏下方。 |

构建和签名验证已通过。当前 ADB 无连接设备，无法采集 APK 的实机截图与效果图做像素对比。不同手机的系统状态栏、导航栏、系统字体和权限弹窗也由 Android 决定；因此本检查不能证明“一模一样”。下一次实机核对重点：删除弹窗尺寸、双列滚轮在窄屏上的文字显示、输入法弹出时保存按钮的位置，以及搜索空状态的垂直居中。
