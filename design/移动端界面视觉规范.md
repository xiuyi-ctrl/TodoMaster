# 咻咿待办 · Android 界面美术规范

应用名称统一为 **咻咿待办**；“咻咿”是一朵轻盈的小云，作为空状态和提示的陪伴形象，不承担功能按钮的职责。整体气质为**可爱但清晰的手账**，让待办内容比装饰更醒目。本规范的主要样式已应用到 Android 工程。

## 后续界面的统一风格

后续新增或修改的界面以当前应用的奶油色背景、墨紫文字、糖果紫交互、浅薰衣草点缀和咻咿云朵为基准。优先使用紧凑的圆角卡片、清晰的文字层级、轻描边与轻阴影；装饰应衬托内容，不占用主要操作空间。设置首页采用图标、标题、当前状态、最右侧进入箭头的横向卡片布局；同类入口保持一致。不同屏宽、系统字体大小及内容长度下，文字不得被截断或与图标重叠。

## 色彩与字阶

| 用途 | 色值 | 用法 |
| --- | --- | --- |
| 奶油背景 | `#FFF9F2` | 所有页面底色 |
| 墨紫正文 | `#3B3551` | 标题、正文、主要图标 |
| 糖果紫 | `#8D73E8` | 主按钮、选中项、焦点 |
| 浅薰衣草 | `#F0E9FF` | 筛选项、类别标签、浅提示面 |
| 蜜桃粉 | `#FFC8B5` | 高优先级、逾期提示、删除确认点缀 |
| 薄荷绿 | `#BFE9D6` | 已完成状态、成功提示 |
| 奶油黄 | `#FFE8A8` | 少量装饰星点 |
| 白色 | `#FFFFFF` | 输入框、任务卡片、弹窗 |

文字使用系统无衬线字体，保证 Android 中文显示一致。页面标题 24sp，卡片标题 17sp，正文与输入 15–16sp，辅助信息 13sp。正文对背景保持足够对比度，状态同时用文字和图标表达，不能只靠颜色。

## 组件样式

| 组件 | 外观与状态 |
| --- | --- |
| 顶部栏 | 小云图标、咻咿待办名称、搜索及更多操作；新建/编辑/回收站用返回箭头和页面标题 |
| 主按钮 | 糖果紫实底、白字、16dp 圆角、至少 52dp 高；底部固定并避开系统手势区域 |
| 次按钮 | 白底紫色描边；取消、恢复等操作使用；删除动作以蜜桃色明确区分 |
| 状态筛选 | 未完成、全部、已完成三段；选中为紫底白字，其余为浅底墨紫字 |
| 任务卡片 | 暖白到极浅粉的渐变底、淡紫描边、圆角和极轻阴影；左侧勾选框，标题优先，其下为分类/优先级，截止时间与“提醒我”在同一行 |
| 完成勾选框 | 未完成为空心墨紫描边，已完成为薄荷绿填充勾；完成任务标题降低对比度 |
| 分类标签 | 浅薰衣草底、墨紫字；与优先级标签保持相同高度，必要时可换行 |
| 优先级标签 | 高：蜜桃；中：浅紫；低：薄荷；标签始终带“高/中/低”文字 |
| 输入框 | 极浅紫底、淡紫描边、12dp 圆角；标题栏用紫色铅笔图标与红色必填星号，标题有内容时显示右侧清除图标；聚焦时描边变糖果紫；错误时显示明确文字 |
| 日期/时间选择 | 统一圆角选择框、日历/时钟线性图标；在设置中选择应用内双列滚轮或原先的 Android 日期、时间弹窗；未设置时显示“选择日期/时间” |
| 提醒选择 | 可滚动的圆角弹窗提供 5 分钟、15 分钟、30 分钟、1 小时、1 天及自定义提前量；自定义按天、小时、分钟输入；下方说明已选提醒时间，通知不可用时展示原因及开启路径 |
| 搜索框 | 放大镜、占位文字和清除按钮；无结果时使用小云插画与“清空搜索”操作 |
| 更多菜单 | 只展示现有操作：编辑、删除、回收站入口；菜单项高度至少 48dp |
| 删除确认 | 白色圆角弹窗，蜜桃色删除图标，说明“移入回收站后可恢复”，取消与删除并列 |
| 轻提示 | 状态栏下方短暂消息，例如“已保存待办”“已移入回收站”；成功使用薄荷色点缀 |
| 系统通知 | 使用 Android 通知容器，应用图标为小云；标题写任务名称，内容写截止时间及提醒原因 |

所有可点击目标至少 48×48dp；装饰星点与云朵不得覆盖按钮、遮住文字或看起来像可点击功能。

## 页面与状态

1. **待办清单：** 顶部栏、待完成/已完成计数、状态筛选、任务卡片、底部“添加待办”。普通任务按创建时间倒序显示，新任务在最上方；列表滚动，底部按钮保持可见。
2. **清单空状态：** 居中咻咿云朵和手账，文案“还没有待办事项”，下方仍保留添加按钮。
3. **新建/编辑：** 标题、备注、分类、优先级、截止时间、提醒分别使用紧凑的圆角分区；日期与时间各占一行，底部固定“保存待办”。内容可滚动，键盘弹出时不遮住当前输入项。
4. **搜索：** 顶部搜索输入，可组合筛选分类、完成状态、优先级和截止时间；时间预设为全部、已逾期、今天、未来 7 天、无截止时间。筛选区可收起并重置；结果使用相同任务卡片，无结果时显示轻量云朵和“清空搜索”。
5. **回收站：** 紧凑白色卡片仅显示标题、相对删除时间和描边“恢复”按钮；空回收站使用简洁文案。
6. **完成与逾期：** 完成使用薄荷绿和已勾选状态；逾期用蜜桃提示与“已逾期”文字。提醒已触发或通知权限关闭也要有文字说明。
7. **确认与权限：** 删除确认使用居中的圆角卡片、珊瑚色垃圾桶、居中文案和取消/删除双按钮；通知说明使用云朵插画与上下排列的按钮。Android 系统权限弹窗保持系统原生样式，不伪装。
8. **设置：** 从首页更多菜单进入；日期选择方式提供“滚轮选择”和“系统日期与时间弹窗”，选择在本机保存，之后的新建和编辑立即使用。
9. **定时任务：** 点击“我的待办”标题切换到独立的“定时任务”页面，再次点击返回。沿用列表卡片与配色；新建表单选择首次执行时间及每天、每周或每隔 N 天的周期，卡片可暂停、继续和删除。执行时间到达时发送通知；设置了提前提醒时，也按所选提前量发送通知。完成当前一次不改变下一次执行时间。

## 动态适配

- **320–359dp：** 左右 16dp 留白；日期与时间上下排列；分类和提醒选项可横向滚动；任务元数据自然换行。
- **360–411dp：** 左右 16dp 留白；三段筛选保持单行；任务卡片与表单纵向滚动。
- **412dp 及以上：** 左右 20dp 留白；日期与时间可并排；卡片增加内部留白，仍维持单列任务流。
- 高度随文字内容与系统字体缩放增长，不固定任务卡片高度。底部按钮与系统状态栏、手势栏、键盘保持安全间距。
- 所有状态使用相同配色和图标规则；暗色模式暂不进入本轮美术设计。

## 状态切换动效

- 勾选任务后立即保存状态并更新提醒；勾选框用约 180ms 的轻微弹性放大，卡片与标题颜色在约 230ms 内过渡。
- 当任务不再属于当前筛选结果时，卡片在约 260ms 内淡出、缩小并收起高度，下面的任务随布局上移。
- 顶部“未完成／全部／已完成”切换时，紫色选中块在约 220ms 内滑动，列表先淡出后淡入。
- 系统关闭动画时直接呈现最终状态。连续点击以最后一次操作为准。
